UIForge
UIForge is an AI-powered UI component generation platform that enables developers and designers to instantly generate, preview, and export production-ready frontend components. 
Built with a modern React + TypeScript stack, UIForge streamlines the UI development workflow by leveraging AI to produce clean, customizable code components on demand.

🚀 Live Demo
🔗 https://ui-forge-app.vercel.app/

🛠️ Tech Stack
Frontend: React, TypeScript, Vite, Tailwind CSS, shadcn/ui
Backend: Supabase (Auth, Database, Storage)

Hosting: Vercel

✨ Features
AI-driven UI component generation
Real-time preview of generated components
Export ready-to-use code
Clean, responsive design system
Fast performance with Vite bundler
